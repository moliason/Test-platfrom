# Test-platfrom

Test-platfrom is a self-hosted platform for managing test cases and test execution.

## Test Management

- Organize cases by project and folder, with a tree view for case details.
- Import Excel cases and update matching case titles.
- Create test runs or add cases to existing runs.
- Assign cases, record results and comments, and track execution progress.
- Export Excel test reports with one sheet per folder.
- Manage project members, roles, and project-specific case types.

## Deployment

The application uses PostgreSQL and supports optional OIDC single sign-on. See [Self-hosting](./getstarted/selfhost.md) for setup options.
